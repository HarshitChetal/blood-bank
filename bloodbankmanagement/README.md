# Blood Bank Management System
---
## Overview
[cite_start]A web-based application designed to efficiently manage blood donation, storage, and distribution processes. [cite: 13]

## Features
- [cite_start]**Admin**: Manage donors, patients, and blood stock. [cite: 637, 644]
- [cite_start]**Donor**: Donate blood and view history. [cite: 646, 647]
- [cite_start]**Patient**: Request blood and track status. [cite: 651, 653]

## How to Run
1. [cite_start]Install requirements: `pip install -r requirements.txt` [cite: 655]
2. [cite_start]Run migrations: `python manage.py migrate` [cite: 656]
3. [cite_start]Start server: `python manage.py runserver` [cite: 656]
